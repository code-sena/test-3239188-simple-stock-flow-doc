# Git Conventions — Simple Stock Flow

## 1. Commit Message Format
Commits must follow a clear, descriptive convention:
* `feat: add product entity validation rules`
* `docs: update hexagonal architecture overview`
* `fix: correct stock movement invariant calculation`

## 2. Branching Strategy
* The main branch (`main`) serves as the stable source of truth. Direct updates or structural forks are managed via organized commits.
